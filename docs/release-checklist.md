# Release checklist

- [ ] Exact source commit passed Quality, including installed-wheel E2E and exFAT.
- [ ] Source, tag, wheel, sdist, and installed command agree on the version.
- [ ] Private downloaded artifacts match SHA256SUMS.
- [ ] Private Homebrew formula passed macOS install and dependency inventory checks.
- [ ] Installation instructions and the private release ledger describe observed results.

Earlier beta evidence is retained in the owner's private recovery archive.
This checklist describes verification to perform, not an assertion that it passed.
